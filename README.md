# GPU Programming Notes

Tutorials on GPU programming, covering CUDA fundamentals and an AMD track on
how AITER and hipBLASLt build high-performance GEMMs. They come with **tested
solutions to every [LeetGPU challenge](https://leetgpu.com/challenges) (101)
and every [Tensara problem](https://tensara.org/problems) (84)**.

The site version of these notes has a page for every tutorial and every
problem, with the full solution source. How to deploy it is covered in
[tutorials/08-deploying-this-site.md](tutorials/08-deploying-this-site.md).

## Layout

```
tutorials/            concept chapters, read in order (00, 01, ...); amd/ holds HIP example code,
                      gemm/ the GEMM deep-dive pages and programs, figures/ the generated SVG figures
leetgpu/NNN-slug/     README.md (write-up) + solution.cu (solution.py for PyTorch-only challenges)
tensara/slug/         README.md (write-up) + solution.cu
tools/cuemu/          CPU CUDA emulator + test runner: checks solutions without a GPU
scripts/              fetch upstream problems, scaffold folders, build README index, figures and the site
mkdocs.yml            site theme; the page tree is generated by scripts/build_site.py
```

## Workflow

```bash
# 1. Fetch the upstream problem definitions (not vendored; see "Licensing") and scaffold new problems
scripts/fetch_upstream.sh
python3 scripts/sync_problems.py

# 2. Solve: edit solution.cu, write the README (set `status: solved`), then test on the CPU
pip install torch==2.14.0 --index-url https://download.pytorch.org/whl/cpu && pip install -r requirements-test.txt
python3 tools/cuemu/run_tests.py leetgpu/001-vector-add

# 3. Refresh the tables below (and the figures, after editing scripts/figures/) and preview the site
python3 scripts/build_index.py
python3 scripts/build_figures.py
pip install -r requirements-docs.txt
python3 scripts/build_site.py && mkdocs serve -f build/mkdocs.yml

# 4. (optional, needs nvcc) compile-check every solution
make check
```

CI (`.github/workflows/ci.yml`) runs these jobs:
- compiles every solution and GEMM tutorial program with `nvcc`;
- runs every solution against the platforms' reference implementations on
  the [cuemu](tools/cuemu/README.md) CPU emulator;
- runs the GEMM deep-dive programs (`tutorials/gemm/`) on cuemu, including
  their `cp.async`, `ldmatrix` and `mma.sync` code paths;
- compiles the AMD example for gfx942;
- checks that this index, the figures and the site build are current.

`.github/workflows/pages.yml` deploys the site to GitHub Pages on every push
to `main`.

| III · AMD GPUs | 05–07 | CDNA3 & MFMA, AITER's hand-written asm GEMM, hipBLASLt & TensileLite |

  problem repository has no license, so no problem statements or reference
  code are copied here. Each README is my own summary and links to the
  official statement.
- **Upstream definitions.** `scripts/fetch_upstream.sh` clones the upstream
  definitions into the git-ignored `.upstream/`, and only the test runner
  uses them.

## Code Conventions

- Classes / structs: `PascalCase`
- Functions, kernels, lambdas: `camelCase`
- `constexpr` / `const` globals: `kCamelCase`
- Other variables, parameters, namespaces: `snake_case`
- Platform entry points (`solve`, `solution`) keep the exact name from the starter code.
- Comments in English.
